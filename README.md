AquaAlert

Smart Community Health Monitoring and Early Warning System for Water-Borne Diseases

Objective

To identify villages that are at risk of water-borne diseases and provide an early warning.

Technologies Used

- Python
- Flask
- SQLite
- Render
- GitHub

Features

- Enter village details
- Predict High Risk or Low Risk
- Save data in SQLite database
- View village reports
- View dashboard with total, high-risk, and low-risk villages
